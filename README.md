## 🛠️ Local Development & Setup

To clone and run this portfolio website locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/myaseen12/muhammad-yaseen-portfolio.git
   cd muhammad-yaseen-portfolio
   ```

2. **Launch local development server**:
   - Using Python:
     ```bash
     python -m http.server 8000
     ```
   - Using Node / npx:
     ```bash
     npx serve .
     ```

3. **View in Browser**:
   Open `http://localhost:8000` in your web browser.
